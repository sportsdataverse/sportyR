# Softball Pitcher's Circle

The pitcher's circle. This is a circular line with its outer edge a
fixed radius from the center of the front edge of the pitcher's plate.
The circle is drawn with its center at the origin, and is anchored to
the front edge of the pitcher's plate when plotted

## Usage

``` r
softball_pitchers_circle(
  pitchers_circle_radius = 0,
  pitchers_circle_thickness = 0
)
```

## Arguments

- pitchers_circle_radius:

  The radius of the pitcher's circle, measured to the outer edge of the
  line

- pitchers_circle_thickness:

  The thickness of the chalk line that comprises the pitcher's circle

## Value

A data frame of the pitcher's circle's bounding coordinates
